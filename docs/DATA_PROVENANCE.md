# SeaLens data provenance

SeaLens distinguishes demonstration inputs from archived public data and model output. A visible API/UI label is part of every investigation result; no label means a result has not been verified for operational use.

| Input or output | Classification | What is known | What is not claimed |
| --- | --- | --- | --- |
| Default scenario SAR signatures, AIS tracks, weather and currents | SYNTHETIC | Authored scenario definitions in `backend/scenarios_data.py`; scenario rasters are generated by `GeoTIFFProcessor.generate_synthetic_geotiff`. | A real spill, live AIS feed, or observed environmental field. |
| Wakashio validation scenario | HISTORICAL_BACKTEST | Publicly documented grounding facts are separately cited in the dossier; its scenario inputs include demonstration estimates. | An independent real-time investigation or a date-specific reanalysis. |
| Sentinel-1 RTC crop selected in Real Data Mode | REAL_ARCHIVED | Public Element 84 STAC/RTC archive, with Copernicus attribution and requested asset URL recorded in audit logging. | A labelled oil-spill ground truth or live satellite product. |
| NOAA/BOEM MarineCadastre import | REAL_ARCHIVED | Historical public AIS broadcasts, retained only for the requested spatial/time subset. | Complete receiver coverage, verified registry data, or proof of vessel responsibility. |
| NOAA GFS wind / Copernicus Marine currents | REAL_MODEL_OUTPUT | Provider grids when retrieval succeeds; source per vector is reported in the API result. | Direct measurement at the slick. |
| DynamicOceanGridEngine fallback | MODELLED | Formula-generated fallback used for offline demos or missing provider coverage. | NOAA, Copernicus, or observed data. |
| `ml_engine/checkpoints/sar_unet_oil_spill.pt` | NOT VERIFIED | The committed `train_sar_unet.py` can generate synthetic training tiles. | The exact checkpoint training run, real-data training set, metrics, or a validated operational model. |

## Current public-data verification

The default historical case is Texas Gulf Coast, 10 January 2020. During this audit, the public Sentinel-1 STAC query returned a scene and the selected RTC crop was downloaded successfully. The resulting local crop was 506 x 202 pixels, EPSG:4326, SHA-256 `606c3130f50ec37424cdd618de6914ad38c8514990916e6b414fb960c7f1365f`.

The NOAA national AIS archive request did not finish before the configured safe timeout. No AIS result is represented as imported, correlated, or validated by this audit. Copernicus Marine credentials are not configured on this machine. The historical 2020 case is outside GFS's operational forecast window, so its wind/current result must remain a clearly labelled modelled fallback.

## Raster and model path

The real Sentinel RTC crop is a georeferenced analysis-ready Gamma0 VV GeoTIFF. `GeoTIFFProcessor.read_geotiff` reads band 1 and applies percentile normalisation for U-Net inference; the CA-CFAR detector receives the separately read unnormalised raster path. This is a processing compatibility statement, not an accuracy validation. The U-Net checkpoint has no recorded training run or held-out real-scene metrics; users must not describe it as trained or validated on a particular real dataset.
